# Changelog

## Unreleased
- Model gateway: five diagrams for the five Privilege model-gateway labs, loaded by name (rule 17): `model-fallback`, `semantic-cache`, `model-armor-inspector`, `bedrock-assumed-role`, `rate-limit-bucket` (`MODEL_GATEWAY_DIAGRAMS` in `core/src/apps.js`), in a new "Model gateway" section of All diagrams. The vendor release notes are the only source; anything beyond them is labelled "lab model" or "UNVERIFIED" in the diagram text.
- Tag review pass: product tags now count a box named after a Ping product double ("PingOne Agent Gateway", "PingOne Authorize"), a hyphenated `ping-gateway` is PingGateway, and a standard needs two steps citing it (or a mention in the words) to become a tag, so a diagram that lists a dozen RFCs once each is no longer tagged with all of them. 43 diagrams gained or lost tags (63 added, 8 removed, plus the standards that no longer follow from a single cite), and `TAG_OVERRIDES` carries the corrections the rules cannot make (the pi.flow family is not PingFederate, Mock Authorize is a mock of PingOne Authorize, the hostile family is a test load in the load-balanced topology, and so on).
- Hygiene: two PingOne environment ids, shortened to their first 8 characters, were in shipped diagram text (the `pf-cedar` library entry and one converted flow). They are now "environment A" and "environment B", and `hygiene.test.js` fails on any other 8-character hex id-like string (the placeholder `a1b2c3d4` is allowed).
- All diagrams is the front door from the demo shelf: `/#all` opens the index (the shelf's open path allows a fragment, not a query), and `docs/shelf-entry.json` sets `openPath` to it. Leaving the index takes `#all` out of the address.
- All diagrams: tags and grouping like the demo shelf. Tag groups and ids match the shelf (Ping products, Subjects, Standards and protocols); "Filter by tag" chips are alternatives inside a group and all apply across groups, with counts; "Group by" Section, Ping product, Subject or Standard; a **Ping product** menu that lists only the products found in diagrams, with counts; the tag panel has a Close button and remembers open or closed; the view is in the address (`tags`, `q`, `group`). Tags are derived from each diagram's own words and cited standards by score (`core/src/tags.js`), with a short list of curated corrections.
- All diagrams: an index page (header button, or `/?view=all`) that lists every diagram in sections that follow the demo family's diagrams page (Architecture, Tokens and delegation, Agent privilege, Personal agent, Agent onboarding and audit, Sign-in and approval, Lab flows, Basics, More), with a filter; each card is a link. Lists, as text, the demo diagrams that are not here and why. Sections come from `core/src/sections.js`.
- 40 more diagrams converted from the demo family's own diagram pages with generic names: 29 flow configs (`core/src/converted-flows.js`) and 11 Mermaid sequences drawn as lifeline sequences (`core/src/converted-sequences.js`). The studio now ships 92. The flow of server topology, live and editable pages, and two customer-specific pages are left out. Step text for the converted sequences is mechanical and its standards links come from keyword rules: review before relying on them.
- Sequence layout: `"layout": "sequence"` draws a diagram as lifelines and numbered messages in order, with phase `bands`, yellow `notes` and `alt` / `loop` / `opt` `blocks`, in the look of the reference Lucidchart sequence (lavender boxes, purple lifelines, black arrows with numbered discs). Click a message for its step, example request / response and standards; click a lifeline for its role and its messages; Simulate keeps the message in focus in view. Pure `sequenceLayout` in core feeds the canvas and the SVG / PNG / HTML exports. Optional `step.refs` cites RFCs and a short list of specs (the link is built by the studio). Steps limit raised from 60 to 120. Tidy spaces lifelines evenly. The HTML export lists a step's standards as text (it stays free of links).
- Box details: click a box and it expands in place, details below its title: its group, its code pointers (links to the pinned commit), reach (boxes upstream and downstream along the arrows), and the boxes it sends to and receives from (each opens that box). Click again, Close, or the empty canvas collapses it; Copy link and `?d=<id>&box=<box>` open a diagram with a box expanded. Pure `boxPassport` in core.
- Apps: the flow of cedar-act-sub-LAB (`cedar-act-sub-flow`, `CEDAR_ACT_SUB_FLOW`) joins the app diagrams, so that lab loads its diagram by name from studio data (rule 17).
- Apps: the flow of cedar-in-privilege-LAB (`cedar-in-privilege-flow`, `CEDAR_IN_PRIVILEGE_FLOW`) joins the app diagrams, so that lab loads its diagram by name from studio data (rule 17).
- Arrow labels: drawn above the boxes (not as SVG text under them) and placed so no two overlap and none sits on a box; the label of the arrow being walked turns blue and bold and is raised above the others during Simulate; a click on a label selects its arrow. Across the 49 diagrams the studio ships, label overlaps measured in the browser went from 37 to 0 and labels sitting on a box from 82 to 1.
- Validator: an arrow may carry an optional `color` (the group color names). Already accepted by the validator copies in the labs that draw coloured arrows; now the canonical validator agrees. The studio does not draw it yet.
- Optional `sources` on a node (repo-relative path and line range, up to 3) and `repo` on the diagram (https URL and 40-character commit): shape checked by the validator, shown in the box detail as links to the pinned commit, and `core/src/verify-sources.js` for a lab's own test to check the files and line ranges exist.
- Verification mark in the header: the shared `VerifyMark` (vendored byte for byte, pinned, from AI-DEMO-Standalone `shared/verify-mark`) shows this lab's own Verified / In progress mark from the demo shelf, inside the header menu beside the Shelf link. It uses the same `api/shelf` call as the Shelf link, so it shows when that call reaches the shelf (through the lab-proxy) and nothing when the lab runs on its own port, the shelf has no mark for it, or the shelf is unreachable.
- On the wire: optional `step.wire` (request, response, tokens decoded claim by claim with plain-language meanings, notice, or a no-traffic note) shown in the step list, detail panel, presenter and embed views and the HTML export. Example data for 10 token and MCP flows (`core/src/wiredata.js`); signatures are always `sig-not-real`.
- Conformance: `CLAUDE.md`, `docs/safety.md`, a forbidden-strings CI job, `MODE=mock`, and SE-cluster manifests with a dry-run deploy script (not deployed).
- Save as HTML: one self-contained, offline walkthrough file.
- Undo/redo (drag = one step), Tidy auto-layout, and New diagram from templates.
- Export SVG and Export PNG for decks (pure `toSvg` in core, collision-aware label placement, canvas PNG capped at 8192 px).
